# العرباوي — خادم التعرف على الخطوط العربية من الصور

موقع + خادم خاص لتحديد اسم الخط العربي المكتوب في صورة **كلمةً أو جملةً كاملة**
(بلا تقطيع للحروف)، بأعلى جودة ممكنة: لا تخمين عشوائي، بل **مطابقة شكلية
مرسومة**: كل خط في مكتبة الخادم يُرسم به نفس نص الجملة (بتشكيل HarfBuzz
كامل: وصل ولزقات واستبدالات) ثم تُقارن السمات الشكلية لكل كلمة ولكل السطر.

## كيف يعمل (خط الأنابيب)

1. **تحسين الصورة** `server/enhance.py`
   تدرّج رمادي ← تقدير الخلفية وتطبيع الإضاءة ← تمدد تباين ← إزالة ضجيج وسيط
   ← ثتننة Otsu ← تصحيح الميل ← تنظيف مشروط للنقط الطفيلية.
2. **تقسيم الكلمات** `server/segment.py`
   المكوّنات المتصلة ≈ كلمات + نقاط. النقاط تُضم لكلمتها، وصناديق الكلمات تُوسَّع
   لتشمل نقاطها. **إن عُرف عدد كلمات الجملة** (من OCR أو إدخال المستخدم) يُصحَّح
   التقسيم إليه بدمج أقرب المجموعات أو الشق عند وديان الحبر — فلا تُجزأ الحروف أبدًا.
   الترتيب عربي: يمين → يسار، ويُحسب عدد الكلمات وعدد الأسطر (الجمل).
3. **التعرف الضوئي على النص** `server/ocr.py`
   محرك EasyOCR (نموذج `arabic` + كاشف CRAFT) إن وُجدت النماذج في
   `data/easyocr_models` (نزّلها مرة واحدة: `python3 tools/fetch_ocr_models.py`).
   إن غاب المحرك يبقى الحقل قابلًا للإدخال اليدوي في الواجهة مع بقاء عدّ الكلمات تلقائيًا.
4. **المطابقة** `server/matcher.py` + `server/features.py`
   لكل خط: رسم كلمات النص بارتفاع حبر مطابق لكلمة الصورة (حلّ بمسحيتين)،
   ثم سمات على مستوى الكلمة: صورة معيارية ١٢×٣٢، إسقاطات أفقية/رأسية، سماكة
   الضربة (تحويل مسافة)، **نمط النقاط** (عدد + مواضع نسبية بترتيب عربي)، عدد
   العيون/الحلقات، موضع خط الأساس، نسبة العرض — إضافة إلى درجة تشابه للسطر
   كله يلتقط إيقاع الوصل والمسافات. الثقة نسبة مئوية مع فارق عن المركز الثاني.
5. **مخزن الخطوط** `server/fontstore.py`
   رفع عبر API أو وضع الملفات في `data/fonts_inbox` (يلتقطها الخادم عند الإقلاع).
   عند الإضافة يُحلَّل الخط: تغطية المحارف العربية، سماكات، ارتفاعات، أسماء العائلة/النمط،
   ويُفهرس في SQLite مع بصمة SHA-256 (منع التكرار). **حصة التخزين قابلة للرفع**:
   `ARABAWI_STORAGE_QUOTA_GB` (افتراضي ٢٥٠ ج.ب) أو قرص خارجي عبر `ARABAWI_DATA_DIR`.

## التشغيل محليًا

```bash
pip install -r requirements.txt          # المحرك والواجهة
pip install -r requirements-ocr.txt      # اختياري: محرك OCR
python3 tools/fetch_ocr_models.py        # اختياري: نماذج OCR
python3 tools/fetch_demo_fonts.py        # اختياري: ١٣ خطًا عربيًا حرًا للتجربة
./run_server.sh                          # http://localhost:8000
```

## النشر كخادم خارجي خاص

```bash
docker build -t arabawi .
docker run -d -p 8000:8000 \
  -v arabawi_data:/app/data \
  -e ARABAWI_STORAGE_QUOTA_GB=1000 \
  --name arabawi arabawi
```

اربط نطاقك/شهادتك أمام المنفذ ٨٠٠٠ (CORS مفتوح لاستدعاء API من أي موقع).

## API

| الطريقة | المسار | الوصف |
|---|---|---|
| GET | `/api/health` | حالة الخادم |
| GET | `/api/storage` | الحصة والاستخدام وحرّ القرص وعدد الخطوط |
| GET | `/api/fonts` | الخطوط المفهرسة + تحليلها |
| POST | `/api/fonts` | رفع خط (multipart: file, name?, license?, source?) |
| DELETE | `/api/fonts/{id}` | حذف خط |
| GET | `/api/ocr/status` | حالة محرك التعرف الضوئي |
| POST | `/api/identify` | صورة (+ text? لتصحيح/إدخال الجملة) → تحسين + كلمات + عدّها + OCR + أفضل ٥ مع معاينات |
| GET | `/api/preview/{id}.png?text=` | معاينة نص مرسم بخط معين |

مثال استجابة `/api/identify`:

```json
{
  "word_count": 3,
  "line_count": 1,
  "words": [{"box": [457, 38, 620, 131], "dots": 1}],
  "ocr": {"text": "الخط العربي جميل", "confidence": 0.91},
  "text_used": "الخط عربي جميل",
  "matches": [
    {"rank": 1, "name": "Amiri", "license": "OFL", "source": "خطوط جوجل",
     "confidence": 82, "word_scores": [0.81, 0.79, 0.84],
     "preview_url": "/previews/….png"}
  ]
}
```

## بطاقة «أفضل ٥»

المقارنة المرجعية لكن بخطوط عربية بالكامل وبدون أي نص إنجليزي
(حتى الأرقام هندية: ٠١ ٠٢ …).

## ملاحظات الجودة

- كلما كانت الصورة أنظف (مسح ٣٠٠dpi فأعلى، تباين جيد) ارتفعت الثقة.
- الجمل شديدة الكثافة الخطية (رقعة/ديواني متشابك) مع ضجيج عالٍ قد تقل ثقتها؛
  عدّل نص الجملة يدويًا لإعادة المطابقة بعدّ كلمات صحيح.
- إضافة خطوط العائلة نفسها بأوزان متعددة تحسّن التمييز بين الأوزان.

## بنية المستودع

